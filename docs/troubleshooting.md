# 常见问题

## 控制台无法粘贴脚本

部分浏览器会阻止向开发者工具控制台直接粘贴代码。按控制台提示完成允许粘贴操作后，再粘贴完整脚本。详细步骤见[无后端模式](backend-free.md)。

## 页面没有自动启动任务

确认已登录学习通且位于 `mooc1.chaoxing.com/mycourse/` 下的课程页面。桌面端在该类
页面加载完成后注入自动化脚本，随后还需在确认框选择“确定”；选择“取消”不会开始任务。
`mooc2-ans` 页面只读取课程元数据，登录页只执行登录辅助，不会启动课程任务。

可刷新课程页面或重新进入课程后重试，并检查日志中的 URL 类别、脚本注入失败和
DOM 等待超时信息。这里的刷新是用户重试操作，应用启动时并不会主动刷新课程 WebView。

## 课程状态没有更新

课程 WebView 每次页面加载完成都会先发送 `cancel` 状态，重置仪表盘；这也包括刷新
当前课程页面，而不只切换到其他页面。确认启动后，脚本通过 `send_status` 发送章节、
页签和任务进度，后端将 `status-update` 事件定向发送到 `main`。

仪表盘不是独立的后台进度查询：它依赖这些实时事件；重新进入课程页后需再次确认启动。
浏览器控制台的无后端模式不向桌面仪表盘发送状态。

## 模型请求失败

检查 Provider、Model 和 API Key 是否匹配，并确认网络、账户额度和本地 Ollama 服务状态。修改配置后点击 **Save**。更多说明见[智能答题](usage/ai.md)。

## 特殊课程不兼容

项目尚未覆盖所有课程类型。请先更新至最新版；若仍无法处理，请在 Issue 中提供课程类型、复现步骤、页面截图和已脱敏的错误日志。
