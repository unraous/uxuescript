# 桌面端使用

桌面端以内嵌 WebView 打开学习通页面，并在识别到相应页面后自动注入课程脚本，无需手动打开浏览器控制台。

## 1. 配置模型

打开左下角 **Configuration**，在 **API** 面板依次设置：

1. **Provider**：选择模型供应商（如 DeepSeek、OpenAI、Google 等），支持直接新增自定义供应商。
2. **Model**：选择该供应商下要使用的模型，支持新增或重命名自定义模型。
3. **Endpoint**：接口基础地址（仅在选中自定义 Provider 时可编辑）。
4. **API Key**：供应商访问密钥。输入框失焦后自动遮罩隐藏。

点击底部的 **Save** 按钮后，配置将持久化保存至本地。智能答题说明见[智能答题](ai.md)。

## 2. 调整课程选项

在 **Configuration** 的 **Course** 面板提供以下选项：

- **Perisist Session**：保持课程登录会话（目前处于实验阶段）。
- **Mute Course**：静音课程 WebView 页面音频。
- **Lock Playspeed**：锁定视频播放倍速。
- **Playing Speed**：填写播放速度数值（默认为 2.0）。

修改后点击底部的 **Save** 按钮保存。

## 3. 打开课程并启动任务

1. 在右下角课程 WebView 登录学习通。
2. 打开课程和需要处理的章节。
3. 页面加载后，按课程页弹窗提示启动任务。

课程 WebView 上方的控制栏提供后退、前进、刷新、返回首页和缩放控制。未识别的网址不会注入课程脚本。

## 4. 查看状态

右上角仪表盘显示课程封面、课程名称、当前章节、任务点和章节完成百分比。离开课程页面后状态会重置，重新进入时会接收新的课程状态。

遇到无法启动、状态不更新或课程类型不兼容时，请先查看[常见问题](../troubleshooting.md)。
