# 桌面端使用

桌面端以内嵌课程页打开学习通，并自动注入脚本，无需手动操作浏览器控制台。

## 配置与保存

在左下角 **Configuration** 中调整设置。需要智能答题时，在 **API** 面板配置供应商、模型和密钥，具体步骤见[智能答题](ai.md)；仅处理视频和 PDF 可跳过模型配置。

**Course** 面板提供：

| 选项 | 作用 |
| --- | --- |
| **Mute Video / 自动静音** | 静音课程脚本处理的音视频，默认开启 |
| **Review Answers / 人工核验** | 提交测验前确认答案，默认关闭；选择 Yes 提交，No 留出 30 秒检查后再次询问 |
| **Speed Lock / 锁定倍速** | 填写正数并保持该倍速；留空不调整，默认留空 |
| **Delay / 等待时间** | 开始任务、填题及互动题答案验证前的等待秒数，带随机浮动；留空不额外等待 |

输入完成后先移开焦点，再点击底部 **Save** 保存。正常退出也会保存，强制结束进程不能保证保存。课程脚本在启动时读取选项，运行中修改后需刷新课程页并重新确认启动。

## 启动与停止任务

1. 在右下角课程页登录学习通，进入目标课程章节。
2. 在课程区域的确认遮罩中点击 **Yes** 启动，点击 **No** 取消。
3. 运行中使用课程控制栏的刷新按钮或 F5 终止脚本；刷新后需再次确认启动。

课程控制栏还提供后退、前进、返回首页和缩放。只有识别到受支持的课程页面才会启动课程脚本。

视频中出现可识别的批注时，脚本自动点击“继续学习”，无需另开选项或配置模型。批注与视频互动题分别处理，视频结束后停止等待剩余弹层。

## 作业与考试

配置并保存模型后，在客户端打开受支持的作业或考试答题页面，按提示确认启动。作业、考试的题型、保存方式与适用限制见[智能答题](ai.md#作业与考试)。

## 查看进度

右上角仪表盘显示课程名称、封面、当前章节与任务点。百分比表示已完成章节占统计章节总数的比例。课程页刷新或导航后会重置展示，任务重新启动后再更新。

课程信息来自已采集的课程列表；脚本结束提示不代表客户端另行核验了平台全部任务。遇到无法启动、状态不更新或课程不兼容，见[故障排查](../troubleshooting.md)。
