# 桌面端使用

桌面端以内嵌 WebView 打开学习通页面，并在识别到相应页面后自动注入课程脚本，无需手动打开浏览器控制台。

## 1. 配置模型

打开左下角 **Configuration**，在 **API** 面板依次设置：

1. **Provider**：选择模型供应商（如 DeepSeek、OpenAI、Google 等），支持直接新增自定义供应商。
2. **Model**：选择该供应商下要使用的模型。仅自定义 Provider 支持新增、重命名或删除模型；内置 Provider 的模型列表不可在 UI 编辑。
3. **Endpoint**：完整的请求地址（仅在选中自定义 Provider 时可编辑）。自定义 Provider 使用 OpenAI Chat Completions 协议，需填写包含 `/chat/completions` 的完整接口 URL，程序不会自动补齐路径。
4. **API Key**：供应商访问密钥。输入框失焦后自动遮罩隐藏。

选择、增删改操作和输入框的更改会先更新内存配置；输入完成后请先移开焦点，再点击底部的 **Save** 按钮，将配置持久化保存至本地。正常关闭客户端也会保存配置，强制结束进程则不能依赖此保存流程。智能答题说明见[智能答题](ai.md)。

## 2. 调整课程选项

在 **Configuration** 的 **Course** 面板提供以下选项：

- **Perisist Session**：会话保持选项（界面标签如此拼写）。目前仅保存此配置值，尚未接入登录会话保持逻辑。
- **Mute Course**：静音课程脚本处理的视频，不是整个 WebView 的音频静音开关。
- **Lock Playspeed**：对课程脚本处理的视频应用并锁定 **Playing Speed** 指定的倍速。
- **Playing Speed**：填写播放速度数值（默认为 2.0）；只有开启 **Lock Playspeed** 时，脚本才会应用该数值。

修改会先更新内存配置，点击底部的 **Save** 按钮保存到本地。课程脚本在启动时读取选项；若课程已在运行，需刷新页面并重新确认启动，才会读取修改后的选项。

## 3. 打开课程并启动任务

1. 在右下角课程 WebView 登录学习通。
2. 打开课程和需要处理的章节。
3. 页面加载后，在课程区域的确认遮罩中点击 **Yes** 启动任务，点击 **No** 取消。运行中可使用控制栏刷新按钮或 F5 终止当前脚本；刷新后会再次出现启动确认。

课程 WebView 上方的控制栏提供后退、前进、刷新、返回首页和缩放控制。未识别的网址不会注入课程脚本。

## 4. 查看状态

右上角仪表盘在任务启动后显示课程封面、课程名称、当前章节和任务点；封面与课程名称来自已缓存的课程元数据。百分比为课程中已完成章节数占纳入统计的章节总数的比例，不是当前章节内任务点的完成比例。课程 WebView 每次页面加载完成（包括刷新）都会重置仪表盘，任务重新启动后再接收状态。

遇到无法启动、状态不更新或课程类型不兼容时，请先查看[常见问题](../troubleshooting.md)。
