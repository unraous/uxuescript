# 独立脚本

## 油猴安装

在已安装 Tampermonkey 的浏览器中打开[油猴脚本下载链接](https://github.com/unraous/uxuescript/releases/latest/download/uxuescript.user.js)，按扩展提示完成安装。进入学习通课程学习页面后，脚本会询问是否启动；选择取消不会运行。运行中刷新页面可停止本次执行，新页面仍会询问是否启动。

脚本随正式 Release 更新，无需配置 API Key，不提供章节测验 AI 答题。

## 控制台运行

无需桌面端时，可将发布附件中的 `core.js` 全部内容复制到学习通网页的浏览器控制台执行，无需配置 API Key。本地构建使用 `pnpm build:scripts`，复制生成的 `dist/scripts/core.js`；`injected/` 下的模块源码需先打包。

该模式支持已实现的视频、音频和 PDF 任务，包括可识别的视频内互动题与批注自动点击“继续学习”；不提供依赖桌面后端的章节测验、独立作业和考试 AI 答题。遇到章节测验时会跳过该任务点，请检查平台实际完成状态。

默认开启自动静音、关闭倍速锁定，因此直接复制运行不会自动设置两倍速。

## 操作步骤

1. 登录学习通网页版，进入课程播放页面。

   ![学习通课程播放页面](assets/backend-free/1748434809500.jpg)

2. 按 F12 打开开发者工具，切换到 **Console（控制台）**。

   ![打开开发者工具](assets/backend-free/1748434330109.jpg)

3. 复制完整 `core.js` 并粘贴到控制台。截图中的旧文件名 `main.js` 应替换为当前的 `core.js`。

   ![将脚本粘贴到控制台](assets/backend-free/1748434420451.jpg)

4. 按 Enter 执行，再按页面提示确认启动。

   ![脚本启动后的提示](assets/backend-free/1748434648962.jpg)

## 停止与排障

- 确认框选择“取消”不会开始任务。运行中按 F5 刷新页面可停止脚本；重新运行需再次粘贴。
- 浏览器阻止粘贴时，按控制台提示允许粘贴，再复制脚本。
- 使用中文浏览器界面。课程页面结构或语言变化可能影响任务识别；不兼容时先更新脚本，再提供复现步骤和脱敏日志。
