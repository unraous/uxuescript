# 无后端模式：在浏览器控制台执行脚本

无需使用桌面端时，可将单文件脚本直接复制到学习通网页的浏览器控制台执行。该模式不启动 Tauri 后端，也不需要配置 API Key；仅支持脚本已实现的课程任务，不提供智能答题。

脚本源文件位于 [`src-tauri/src/scripts/core.js`](../src-tauri/src/scripts/core.js)。该文件可独立执行，复制全部内容即可。

无后端模式使用内置默认配置：视频静音开启、倍速锁定关闭。虽然默认倍速值为 `2.0`，
当前实现仅在开启倍速锁定时施加该值，因此直接复制运行不会自动将视频设为两倍速。
支持的视频任务包含脚本可识别的视频内互动题，答案来自页面数据或学习通验证接口，
不调用模型；PDF 任务通过滚动处理。独立 Quiz 任务依赖后端，遇到时会报错并由外层
页签错误处理跳过该页签剩余任务，不会自动答题。

## 操作步骤

1. 登录学习通网页版，进入需要处理的课程播放页面。

   ![学习通课程播放页面](assets/backend-free/1748434809500.jpg)

2. 按 <kbd>F12</kbd> 打开浏览器开发者工具，切换到 **Console（控制台）**。

   ![打开开发者工具](assets/backend-free/1748434330109.jpg)

3. 打开 `src-tauri/src/scripts/core.js`，复制全部内容并粘贴到控制台。旧版截图中的 `main.js` 为旧文件名；当前版本应复制 `core.js`。

   ![将脚本粘贴到控制台](assets/backend-free/1748434420451.jpg)

4. 按 <kbd>Enter</kbd> 执行脚本，随后按页面提示启动任务。

   ![脚本启动后的提示](assets/backend-free/1748434648962.jpg)

## 常见问题

- Edge 等浏览器可能阻止直接粘贴脚本。按控制台提示完成允许粘贴操作后，再粘贴脚本。
- 请将浏览器界面语言设为中文。课程页面结构或语言差异可能影响脚本识别。
- 页面布局或课程类型发生变化时，脚本可能无法识别任务；请更新至最新版后再反馈问题。
- 点击运行确认框的“取消”不会开始任务。运行中可按 <kbd>F5</kbd> 刷新页面终止脚本；
  浏览器模式刷新后需要重新粘贴执行。桌面端识别到课程页加载完成后会重新注入并再次询问是否启动。
